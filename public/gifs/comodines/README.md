# GIFs de los comodines

Al usar un comodín sale un GIF al azar de su categoría. Nombres: `PREFIJO_N.gif`, con N consecutivo desde 1
(si falta el 3, el 4 y siguientes no se usan). No hay que tocar código al añadir más: se descubren solos.

| Comodín              | Prefijo                  |
|----------------------|--------------------------|
| Ruleta               | `RULETA`                 |
| 50/50                | `CINCUENTA_CINCUENTA`    |
| Cambiar pregunta (y la del rival) | `CAMBIAR_PREGUNTA` |
| Doble o nada         | `DOBLE_O_NADA`           |
| Llamada              | `LLAMADA`                |
| Robar                | `ROBO`                   |
| Apostar              | `APUESTA`                |

Ejemplo: `ROBO_1.gif`, `ROBO_2.gif`, `APUESTA_1.gif`.

Ojo: Caddy sirve los `.gif` con caché inmutable de un año, así que para cambiar un GIF publicado
añade uno con número nuevo en vez de sobrescribirlo.
